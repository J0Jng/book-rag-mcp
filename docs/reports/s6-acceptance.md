# S6 全量主题聚类与原文检索验证

2026-10-23：S6 已实现并完成全量归属、命名锚点、只读检索和回归验证。单层聚类的混合/边缘成员局限按本期范围保留。

## 全量与向量复用

五本书全部 **3,257 个 chunk** 归属到8个簇，每个 `(source, position)` 恰好出现一次，section 与原 docstore 一致。直接读取已有 FAISS 中 **1,024维** bge-m3 向量并做 L2 归一化，未重新 embedding。实际构建与验证都禁止调用 embedding 加载器，核心索引哈希保持不变。

`topics.json` 已发布：每簇都有名称、描述、全部成员/count、来源分布、6个代表原文指针和有效命名证据编号。`topics.pending.json` 保存恢复断点。

## K 选择

固定 random_state=42、n_init=10，在全量归一化原向量上做 Lloyd KMeans；余弦 silhouette 的评估样本最多1,500个，以最高分选择K，同分取较小K。原始指标与 inertia 均保存在 `topics.json`、`s6-evidence.json`。

| K | silhouette cosine |
|---:|---:|
| 8 | 0.121440 |
| 12 | 0.115853 |
| 16 | 0.081614 |
| 24 | 0.070430 |
| 32 | 0.063132 |

选择K=8。该指标不证明全簇语义纯净。

## 命名与原文核对

使用经授权的 DeepSeek 官方 API / `deepseek-flash`，只发送代表原文与全簇来源数量；密钥未落盘。标签仅概括**代表片段的主导主题**，工具展示真实来源分布，不声称所有成员同源或观点一致。

Codex 对三个簇分别阅读最近、中位及最远成员，核对名称与原文；这不冒充用户人工复核。完整样本与判断见 `s6-semantic-review.json`。

## 只读工具与验证

- `search_by_topic(query, top_k, per_book)` 匹配主题名/描述或topic-ID，按书返回原文与所属簇及source/section/position。
- 查询不调用LLM或embedding；核心索引变动、标签不完整或旧版描述未限定范围时返回补建提示。每个原文成员最多显示1,200字并明确标注截取。
- 全部成员指针、所有主题ID查询及原文前缀一致性检查通过；真实FastMCP调用通过，9个工具可见。
- 无API key时实跑 `book-rag-mcp topics` 成功复用结果；命名失败只保留断点，不发布不完整主题。
- 最终全量测试 **296 passed**、ruff全绿。证据见 `s6-evidence.json`、`s4-s6-interface-smoke.json`。
